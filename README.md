## ⚙️ Características Técnicas Implementadas
1. **Backend:** Java 21, Spring Boot, Spring Security y Springdoc OpenAPI (Swagger UI).
2. **Base de Datos:** PostgreSQL configurada mediante contenedores y servicios en la nube.
3. **Dockerización:** 
   - `Dockerfile` multietapa optimizado.
   - `docker-compose.yml` (Nivel 2) para levantar base de datos y backend de forma local.
4. **CI/CD:** Pipeline automatizado en GitHub Actions para compilar y publicar imágenes en el Registro de Contenedores de GitHub (`ghcr.io`).
